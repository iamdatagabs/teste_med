# MedVoca — Orientação vocacional médica

Aplicação web estática para reflexão vocacional sobre especialidades médicas.

## Funcionalidades

- Três percursos: Expressa (12 questões), Intermediária (24) e Completa (36).
- Questões de escolha única e múltipla seleção.
- Indicadores de afinidade com especialidades médicas.
- Perfil vocacional descritivo.
- Leitura comportamental inspirada no modelo DISC.
- Arquétipo simbólico de atuação profissional.
- Relatório imprimível / exportável como PDF pelo navegador.
- Interface responsiva para desktop e dispositivos móveis.
- Sem backend, cadastro ou envio de respostas para servidor.

## Como executar

Abra `index.html` em um navegador moderno. Para publicar, habilite GitHub Pages nas configurações do repositório, selecionando a branch principal e a pasta raiz (`/(root)`).

## Metodologia e limites

O resultado é uma ferramenta educativa de autoconhecimento. As pontuações são heurísticas e indicam afinidades relativas entre as respostas e dimensões de atuação. Não representam aptidão clínica, desempenho futuro, probabilidade de sucesso ou recomendação definitiva de carreira.

A leitura DISC é inspirada nos quatro fatores do modelo (Dominância, Influência, Estabilidade e Conformidade), mas não constitui aplicação oficial ou avaliação psicométrica validada. Os arquétipos são metáforas narrativas para reflexão.

As descrições das especialidades são introdutórias e não substituem informações oficiais sobre programas de residência, requisitos de formação, escopo profissional ou condições de trabalho.

## Próximas evoluções sugeridas

- Revisão técnico-científica das perguntas e pesos com médicos de diferentes especialidades.
- Validação de conteúdo e estudo piloto com estudantes de Medicina.
- Refinamento do algoritmo de pontuação e explicabilidade dos resultados.
- Inclusão de todas as especialidades reconhecidas e áreas de atuação, após revisão editorial.
- Comparação entre resultados das três versões e histórico local opcional.

## Privacidade

As respostas são processadas no navegador e não são transmitidas a uma API. O relatório não solicita nome, e-mail ou outros dados pessoais.
